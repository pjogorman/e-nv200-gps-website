e-NV200 GPS Maps

Personal vehicle GPS map processing and email delivery

About this application

e-NV200 GPS Maps is a personal-use application that converts previously collected Nissan e-NV200 vehicle GPS location records into daily KML map files. It packages the generated maps into a ZIP archive and uses Google's Gmail API to email the archive to the account owner.

The application is not a public tracking service and does not offer public access to GPS history or maps. The source data and generated maps are handled in a separate private GitHub repository.

Google account access

The application requests the Gmail gmail.send permission solely to send the generated GPS map email. It does not request permission to read, modify, or delete Gmail messages.

See the Privacy Policy for details.
