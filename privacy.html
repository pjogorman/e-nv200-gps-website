Privacy Policy

e-NV200 GPS Maps · Effective 15 October 2026

Purpose and scope

e-NV200 GPS Maps is a personal-use application that processes GPS location records provided by its owner, converts them to KML map files, and emails the resulting ZIP archive to the owner's Gmail account.

Data processed

Input records may include vehicle coordinates, timestamps, and related location information. Generated KML maps and ZIP archives may reveal travel history and are treated as private information.

Google account permissions

The application requests only the Google Gmail API gmail.send scope. It uses that permission to send map archives as email attachments on behalf of the account owner. It does not request Gmail inbox reading, message deletion, or mailbox management permissions.

Storage and sharing

GPS source records and processing files are kept in a separate private GitHub repository. Authentication credentials are stored as restricted GitHub Actions secrets. The application sends GPS map archives through Gmail to the configured recipient. Information is processed by GitHub and Google to provide these services, subject to their respective terms and policies. The public informational website does not publish GPS records or maps.

Retention and control

The account owner controls the source records, generated files, email messages, and repository access. Data and messages may remain in GitHub or Gmail until the owner removes them, subject to provider retention policies. The owner can revoke the application's Gmail access through Google Account security settings.
